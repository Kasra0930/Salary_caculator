
# Salary Calculator 💼

A Python-based employee management and salary calculation system built with Tkinter.

## ✨ Features

### 👤 Employee Management
- Register new employees
- Search employee records
- Edit employee information
- Delete employee records
- Store personal and employment information

### 📊 Performance Management
- Register monthly employee performance
- Track working days and working hours
- Record overtime hours
- Track night shifts, holidays and missions
- Calculate salary based on recorded performance

### 💰 Salary Calculation
- Calculate base salary
- Add bonuses and allowances
- Calculate overtime and other payments
- Apply tax and insurance deductions
- Calculate final payable salary

### 🧾 Payslip Management
- Search payslips by national ID
- Filter records by year and month
- Display saved salary information
- Store monthly payroll records

## 🛠️ Technologies

- Python 3
- Tkinter
- CSV / File Handling
- UTF-8 Encoding

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
```

Navigate to the project directory:

```bash
cd REPOSITORY
```

## ▶️ Run

```bash
python Salary_Calculator_KSS.py
```

The CSV files are created automatically when needed.

## 💾 Data Storage

Employee information and payroll records are stored locally using UTF-8 encoded text files.

- `employees.csv`: Employee information
- `payroll.csv`: Monthly performance and salary records

## ⚠️ Notes

- This application is designed for desktop use.
- Data is stored locally on the computer.
- Back up your data files regularly.
- Salary calculation rules may need adjustment according to local labor laws.
